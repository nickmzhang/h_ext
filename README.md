# h_ext
# Test extension

Example Hayase extension repository.

## Files

- `manifest.json` — Extension manifest
- `nyaa.js` — Extension logic
- `assets/icon.png` — Extension icon

## Hosting

Host the repository with static hosting such as:

- GitHub Pages
- Cloudflare Pages
- Netlify
- Vercel

Ensure:
- `manifest.json` is publicly accessible
- `nyaa.js` supports CORS
- icon URLs are public
